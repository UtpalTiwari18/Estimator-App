# Estimator App

## Description
The Estimator App is a web-based platform that allows customers to submit car service requests and connect with nearby service providers. The system helps improve communication between customers and businesses by organizing service requests, responses, and job tracking in one place.

## Project Purpose
The goal of this project is to provide a fast and efficient system where:
- Customers can request service estimates online  
- Businesses can respond and manage requests  
- The entire process is organized and easy to track  

This reduces confusion from phone calls or paper notes and improves overall efficiency.

## Features
- User account registration and login  
- Submit service/estimate requests  
- Search for services using keywords or zip code  
- Businesses can accept or reject requests  
- Job tracking from start to completion  
- Reviews and ratings system  
- Organized display of services  
- Data stored securely in a database

## How to Run the Project
1. Download or clone the repository  
2. Open the folder in VS Code  
3. Open `home.html`  
4. Click **Go Live** (Live Server)  
5. The website will open in your browser  

## Database Setup
1. Open MySQL Workbench  
2. Run the database file (`estimator.db`)  
3. Update the `.env` file with your MySQL username and password
